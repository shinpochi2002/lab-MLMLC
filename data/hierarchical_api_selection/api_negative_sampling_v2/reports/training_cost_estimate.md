# 本格学習の計算量見積もり

実行した学習ではなく、保存された実件数と上限epochからの算術見積もり。Batch=8、max_length=512、最大50epoch（例外は固定10epoch）。API152個は全16構成で共用し、16倍しない。カテゴリ653個の共有は適用しない。

| 対象 | 条件選択用学習回数 | 最終再学習回数 | 合計 |
| --- | --- | --- | --- |
| API | 1278 | 152 | 1430 |
| カテゴリ | 1322 | 653 | 1975 |
| 全体 | 2600 | 805 | 3405 |


API条件選択は3比率×2lr×213 Fold/Holdoutペア。例外55個には条件選択を行わない。カテゴリは既存661ペア×2lr。最終学習は各分類器1回。

| 対象 | 条件選択の最大optimizer step | 最終学習の最大optimizer step | 条件選択Train service-epoch | 条件選択Validation service-epoch |

| カテゴリ | 9621200 | 6008500 | 76732400 | 19185300 |


上限step合計は16,675,510。選択後のAPI比率・epochは未確定なので、最終学習は通常分類器に最大のTrain集合と50epoch、例外に比率1・10epochを使用した上限。負例比率不足とgroup単位丸めは実件数へ反映済み。ESによる短縮は見込まない。

スモークはCPU2スレッド・32token・4レコード・2epochなので、512tokenのGPU本格実験の所要時間へ換算できない。GPU種別、実batch、sequence length、検証頻度、I/O、利用可能VRAMに依存するためGPU時間は未確認。全データでの1epoch計測が次段階で必要。

学習重みはBERT約438MB/モデルで805個なら概算約353GB（ヘッド・ファイル形式で変動）。実装は条件選択の最良Fold checkpointも保存するため、条件選択モデル2600個をすべて保持するとさらに概算約1139GBを要する。これにはoptimizer状態・データ・キャッシュを含めない。保存/整理方針は本格実験前に判断する。
